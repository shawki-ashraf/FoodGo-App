# 🍔 FoodGo

FoodGo is a modern food ordering mobile application built using Flutter.  
The app focuses on clean UI, smooth user experience, and scalable architecture.

---

## 🚀 Features

- 🍔 Browse burgers and meals
- 🔍 Search for food بسهولة
- 🧾 View product details
- 🛒 Add to cart
- 📦 Order creation flow
- 👤 User profile
- 🔐 Login UI
- ⚡ Clean and modern design
- 🌐 API Integration
- 🧠 State management using Cubit (Bloc)
- 🏗 Clean Architecture
