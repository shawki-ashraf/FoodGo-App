# FoodGo 🍔

FoodGo is a food ordering mobile application built using Flutter.

## 🚀 Features
- Browse burgers and meals
- Clean and modern UI
- API Integration for fetching food data
- State management using Cubit
- Clean Architecture structure

## 🛠 Tech Stack
- Flutter
- REST API Integration
- Cubit (Bloc)
- Clean Architecture
